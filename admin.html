Setup & security

Required configuration before production.

Supabase

Open this page through http://localhost or HTTPS, not file://. This page checks the admin role in public.profiles.role, where profiles.id must match the Auth user UUID.

Registered users

The host and invitee lists use admin_list_live_users(). Users Management uses admin_list_managed_users(). Both functions must check the admin role internally.

Session schema

Uses owner_id, title, description, scheduled_at, join_url, cover_image_url, status, and approved in public.live_sessions.

Account controls

Blocking updates profiles.is_blocked and must be enforced by your app's login flow and data-access policies. Deleting a profile does not delete its Supabase Auth account. Auth account bans/deletion require a trusted server-side component.
