Setup & security

Important checks before using the admin page with real accounts.

Firebase connection

This page imports auth and db from your existing firebase.js file and manages the liveSessions Firestore collection used by your member dashboard.

  • Keep firebase.js beside admin.html.
  • Use the same local server URL pattern: http://127.0.0.1:8000/admin.html.
  • Do not open this page with file:///.

Secure administrator access

The email allowlist in this file protects the page UI, but Firestore security rules must also restrict writes. A browser-only check by itself is not sufficient security.

  • Set your actual administrator email in ADMIN_EMAILS in the script.
  • Apply the Firestore rules shown in the generated instructions before deploying.
  • Never publish service-account credentials or Firebase Admin SDK secrets in this HTML file.

What this page manages

Session title, host, description, emoji, status, approval, creation date, and edits/deletions. Your current member dashboard reads the same liveSessions collection.

Not included yet

Managing Firebase Authentication users, private messages, payments, or reports requires the exact data model and secure backend/Firestore rules. Those should not be guessed or exposed through unrestricted browser code.
