Security

The server verifies your signed-in user and checks profiles.role before it can create an account or send an invitation. Never put the service-role key in this HTML.

Setup & security

Required configuration before production.

Supabase

This page uses Supabase Auth and reads the admin role from public.profiles.role. The Auth UUID must match profiles.id. Use localhost or HTTPS, not file://.

Secure account actions

Deploy the admin-account-actions Edge Function, configure its secrets, and keep JWT verification enabled. Use RLS policies on database tables.

Sessions table

The page expects public.live_sessions with id, title, host, emoji, status, description, approved, created_at, and updated_at.

Invitation setup

Set the Site URL and allowed redirect URLs in Supabase Auth. Configure email delivery and provide an invitation-acceptance page so recipients can finish setup.
